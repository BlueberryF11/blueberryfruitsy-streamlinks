# Blueberry Fruitsy // Stream

The source for **[stream.blueberryfruitsy.com](https://stream.blueberryfruitsy.com/)**, my music streaming hub.

Built with plain HTML, CSS, and JavaScript. No framework. No giant pile of dependencies. Just vibes.

## What's here

- `index.html` — the actual site
- `style.css` — layout, animations, responsive design
- `script.js` — interactive effects and small bits of behavior
- `CNAME` — custom domain configuration

## Music

The site links to my current music pages on Spotify, Apple Music, YouTube Music, TIDAL, and Amazon Music.
